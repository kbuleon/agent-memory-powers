**Execution plans** are produced by **Superpowers** once a **specification** (`20-specs`) has been approved. A plan describes *how* to do the work: breakdown into tasks, files touched, exact content to write, verification commands and commit points. It is executed task by task, with a review after each one.

This file is an index of the **execution plans** in this folder.
This list is kept up to date by the agent.
