A **study** is a one-off document that analyzes either how the repository works (code, setup, integration) or a general topic (third-party component, technology, issue encountered at a customer site). It is written by the agent **at the user's request** and reflects the state of the repository **at the date it was written**: unlike the `50-technical-references`, it is not kept up to date.

This file is an index of the **studies** in this folder.
This list is kept up to date by the agent.
