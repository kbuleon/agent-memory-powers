**Specifications** are produced at the end of a brainstorming on a **work item** (`10-work-items`) that **Superpowers** has classified as `architectural`. A specification describes *what must be true* once the work is done (settled decisions, expected behaviors, etc.).
Each specification then gives rise to an **execution plan** (`30-plans`).

This file is an index of the **specifications** in this folder.
This list is kept up to date by the agent.
