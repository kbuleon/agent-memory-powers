Index of the directories in the `docs/` folder.
# Contents

* `00-knowledge-base/`: general knowledge base.
* `05-draft/`: drafts in progress, outside the workflow.
* `07-studies/`: one-off studies, not kept up to date.
* `10-work-items/`: analyses of requests.
* `20-specs/`: Superpowers writes its specifications here.
* `30-plans/`: Superpowers writes its execution plans here.
* `40-adr/`: Architecture Decision Records.
* `50-technical-references/`: technical reference documents.

# Configuration file
The `work-items-settings.json` configuration file is not indexed.
