An **Architecture Decision Record (ADR)** is the record of a decision that was made, with its context, what was chosen, the consequences and the alternatives that were set aside. An ADR is not rewritten when the decision changes: a new one is created to supersede it. The ADR is dated on the day the decision was adopted. An ADR is **proposed by the agent; its creation is confirmed by the user**.

This file is an index of the **ADRs** in this folder.
This list is kept up to date by the agent.
